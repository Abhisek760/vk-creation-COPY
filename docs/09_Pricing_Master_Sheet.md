# 1. Purpose

This document defines the official pricing structure of VK Creation.

It acts as the Single Source of Truth (SSOT) for all pricing-related information used throughout the software.

This document will be used by:

- Wedding Coverage Builder
- Ready Packages
- Live Price Calculator
- Booking System
- Quote Generator
- Admin Panel
- Future Mobile Application

### Category

### Pricing Rules

If Total Photos ≤ 2000

₹8 / Photo

### Examples

1800 Photos

# 4. General Business Policies

- All prices are in Indian Rupees (INR).
- Prices may be updated by VK Creation.
- Transportation charges are not included.
- Accommodation charges are not included.
- GST is not included unless specified.
- Custom quotations may override default pricing.
