# 1. Purpose

This document defines all ready-made wedding packages offered by VK Creation.

The packages serve as a quick starting point for customers.

Customers can either:

- Book the package as-is
- Customize the package by adding or removing services

This approach combines simplicity with flexibility.

VK Creation currently offers three package levels.

1. Silver Package
2. Gold Package
3. Platinum Package

Future packages can be added without changing the system architecture.

# 7. Package Customization Rules

Customers may:

✔ Add Services

✔ Remove Services (If Allowed)

✔ Upgrade Album

✔ Upgrade Videography

✔ Add Drone

✔ Add Cinematic Film

✔ Add Reels

✔ Add Edited Photos

Every modification updates the quotation instantly.

---

# 8. Live Quote Behaviour

Whenever a package changes:

System recalculates:

• Package Price

• Added Services

• Removed Services

• Discounts (Future)

• GST (Future)

• Grand Total

No manual calculation is required.
